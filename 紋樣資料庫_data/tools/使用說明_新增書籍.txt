公眾版權紋樣資料庫 — 使用說明與「新增書籍」流程
====================================================

一、日常使用
------------
1. 雙擊「公眾版權紋樣資料庫.html」即可（完全離線，不需要網路，也不需要伺服器）。
2. 請把 html 與旁邊的「紋樣資料庫_data」資料夾放在一起；整個資料夾可以複製到別台電腦或隨身碟。
3. 左側由上到下：
   - 圖像類型：照片 / 黑白稿 / 彩色圖稿（點一下篩選，再點一下取消）
   - 紋樣分類：天花板、圓形・徽章・花飾、線板・檐口、柱頭・托架・建築構件、石膏飾件、長條・邊飾、
               大面積・連續花紋、角飾・單體花飾、圖案畫・紋章・人物、綜合圖樣頁、活字・印刷花飾
   - 來源書籍：預設摺疊，需要時點開再選書
   - 兩種篩選可以疊加（例如「黑白稿」＋「長條・邊飾」）
4. 縮圖右上角的 ♡ 加入「我的喜歡」；點縮圖開大圖，←→ 切換、L 喜歡、Esc 關閉，點大圖可在新分頁放大。
5. 「我的喜歡」與手動改過的分類存在這台電腦的瀏覽器裡；按右上「匯出我的整理」可備份成 json，
   把 json 交給 Claude 就能併入資料庫。
6. 一律以「整頁」為單位；分類是「這一頁的主要內容」，一頁裡混有多種圖樣時歸在「綜合圖樣頁」。

二、日後新增書籍（由妳提供 PDF，Claude 依同樣流程製作）
--------------------------------------------------------
妳要做的：
  1. 把新 PDF 放進 D:\資料庫\公眾版權圖書資料庫\公共圖書_紋樣
     （檔名裡加註 (照片) / (黑白稿) 之類的提示會有幫助，沒有也可以）
  2. 對 Claude 說：「新增書籍：<檔名>」，並開啟同一個資料夾連結。
     如果 Claude 是新的對話，請一併說「資料庫在 D:\資料庫\公眾版權圖書資料庫，做法看
     紋樣資料庫_data\tools 裡的說明」。

Claude 的作法（給新對話的 Claude 看；所有腳本都在 紋樣資料庫_data\tools）：
  0. 把 tools 內全部檔案、紋樣資料庫_data\books\*.json、公眾版權紋樣資料庫.html 取到工作目錄
     （tools 放工作目錄，books 放 out/pkg/紋樣資料庫_data/books，模板 template.html 已在 tools 內）。
     只需要新書的 PDF，不必重新處理舊書。
  1. 在 newbooks.json 加一筆：
        "<新id>": {"file": "<檔名>.pdf", "kind": "照片|黑白稿|彩色圖稿",
                   "title": "<完整書名>", "short": "<側欄短名>"}
     然後  python3 mkthumbs.py <新id>   → 產生 thumbs2/<id>/p-NNN.jpg 小圖。
  2. 用  python3 tsheet.py <id> <起> <張數> <欄> <寬> <高> <輸出.jpg>  做編號聯絡表，肉眼挑出「有圖樣的頁」，
     排除封面、文字頁、空白頁、價目表、純建築外觀照片等。
  3. python3 addsel.py <id> "<頁碼，如 11,13,16-23>" "<預設分類>" "<分類=頁碼;分類=頁碼>" "<類型=頁碼;...>"
     - 分類請用 pclassify.py 的 PCATS；類型只有 照片 / 黑白稿 / 彩色圖稿（同一本書內可混合，用第 5 個參數逐頁指定）
     - 頁碼是 PDF 的第幾頁（從 1 起算），不是書上印的頁碼。
  4. python3 finalize.py     （sel.json → books.json、out/pcats_final.json）
  5. python3 pages.py <id>   （整頁轉檔：轉正、去掃描黑邊、長邊 2000px、JPEG）
     照片集若是貼在牛皮紙相簿上，可在 books.json 該書 cfg 加 {"crop_dark": true} 只裁出黑底照片。
  6. python3 pack.py --only <id>   （只封裝這一本；--meta 只重寫索引；--all 全部重做）
     產生新的 thumbs/full 分片、books/<id>.json，並更新 meta.js、html、manifest.json、tools。
  7. 只把「新增或變動」的檔案寫回 D:（對照 manifest.json 的 sha1，舊書的分片不用動）：
     新書的 thumbs/*.js、full/*.js、books/<id>.json，以及 meta.js、html、manifest.json、tools/*。
  8. 用 Playwright 開 html 做基本檢查（初始 100 張、捲動載入、分類/類型/書籍篩選、大圖、喜歡），再回報。

三、資料夾結構
--------------
  公眾版權紋樣資料庫.html            ← 主程式（雙擊）
  紋樣資料庫_data\meta.js            ← 索引（每次更新都會重寫）
  紋樣資料庫_data\thumbs\            ← 縮圖分片（每本書各自獨立）
  紋樣資料庫_data\full\              ← 整頁大圖分片
  紋樣資料庫_data\books\<id>.json    ← 每本書的紀錄（頁碼、分類、類型、分片名）；新增書籍靠它免重做舊書
  紋樣資料庫_data\manifest.json      ← 每個檔案的 sha1
  紋樣資料庫_data\tools\             ← 製作用腳本與設定（books.json / sel.json / newbooks.json = 「食譜」）
  公共圖書_紋樣\                     ← 原始 PDF

  備註：資料夾裡大小只有幾十 byte 的 .js（例如 f_excelsior_016.js）是舊版留下的空殼，可放心刪除，
  tools 裡標示 obsolete 的舊腳本也是。
